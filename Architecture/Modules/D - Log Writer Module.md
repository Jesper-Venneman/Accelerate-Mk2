Writes the final log entry into the project's `Ω - logs` folder.

## Responsibilities
- Write each of the three log types - [Project Log](../Log%20Types/Project%20Log.md), [Unsorted Log](../Log%20Types/Unsorted%20Log.md), [Vocal Journal](../Log%20Types/Vocal%20Journal.md) - using its own `---`-separated file structure (see each note for specifics).
- New logs become part of the vault, so [F - RAG Indexing Module](F%20-%20RAG%20Indexing%20Module.md) picks them up automatically - no separate hookup needed.
